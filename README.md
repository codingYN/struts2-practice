## 使い方
1. Eclipse 2023 (Windows 64 Full Edition) をインストール  
2. Javaプロジェクトを作成  
3. 上記参考資料に従ってStruts2またはGitHub連携の設定を行う  
4. 必要なソースコードを追加・編集して、GitHubリポジトリにコミット・プッシュ
